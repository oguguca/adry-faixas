# Adry Faixas

Site institucional da Adry Comunicação Visual, em Next.js 16.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Build

```bash
npm run build
```

O projeto usa `output: "export"` e o script de build também prepara `dist/` para hospedagem.

## Design

A reformulação atual usa a metodologia UI UX Pro Max. A fonte de verdade visual está em:

- `design-system/adry-faixas/MASTER.md`
- `docs/UIUX_AUDIT.md`

Princípios principais: acessibilidade, mobile-first, fotografia real, grid editorial, laranja como acento e movimento reduzido.
