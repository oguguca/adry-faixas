# Adry Scroll Transition v2

## O que mudou

- O painel 3D não repete mais a lista de serviços.
- Agora ele apresenta o processo:
  1. Entender
  2. Produzir
  3. Aplicar
- A área total da animação foi reduzida de 62rem para 48rem no desktop.
- O espaço vazio entre o painel e os serviços foi removido.
- O painel perdeu o aspecto de "notebook" e virou uma peça gráfica da Adry.
- A lista de serviços abaixo ganhou uma entrada própria e hover mais refinado.

## Dependência
Se ainda não instalou:

npm install framer-motion
